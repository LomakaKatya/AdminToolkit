Типові проблеми

Швидкі пояснення для помилок запуску, доступу, мережі та кодування.

Команда irm не знайдена

Перевірте версію PowerShell:

$PSVersionTable.PSVersion

Для нормальної роботи Toolkit рекомендовано Windows PowerShell 5.1 або PowerShell 7+.

Access is denied

Закрийте Toolkit і відкрийте PowerShell від імені адміністратора. Для BgInfo повторний запуск інсталятора відновлює ACL на каталозі встановлення.

Не завантажується службове джерело або домен

[Net.ServicePointManager]::SecurityProtocol =
    [Net.ServicePointManager]::SecurityProtocol -bor 3072

Перевірте DNS, проксі, TLS 1.2, доступ до домену Toolkit і службового джерела модулів.

Текст перетворився на РќРµ...

Це Windows PowerShell 5.1 прочитав UTF-8 без BOM через параметр -File як локальне ANSI-кодування. Runtime-файли Toolkit залишаються UTF-8 без BOM, а завантажувачі мають читати їх явно з -Encoding UTF8.

Новий пункт не з'явився

Перевірте, що змінений Start-AdminToolkit.ps1 опубліковано в актуальній робочій версії Toolkit. Перезапустіть Toolkit, оскільки меню формується заново при кожному запуску.

Модуль повернув 404 або порожній файл

Перевірте точний шлях, регістр літер і наявність файла у службовому сховищі. Шлях у меню повинен повністю збігатися зі структурою репозиторію.
