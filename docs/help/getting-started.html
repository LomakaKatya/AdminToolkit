Початок роботи

Коротка схема запуску, вимоги та поведінка Toolkit.

Що це таке

Raccoon Admin Toolkit - це меню для запуску окремих адміністративних PowerShell-модулів. Головний файл майже нічого не робить сам: він завантажує актуальний модуль із центрального сховища й запускає його в поточному сеансі.

Як запустити

irm https://admintoolkit.itraccoonverse.space | iex

Для системних змін відкривайте Windows PowerShell від імені адміністратора. Без підвищених прав безпечна діагностика може працювати, але адміністративні модулі будуть заблоковані.

Вимоги

  • Windows.
  • Доступ до HTTPS-домену Toolkit і службових джерел Toolkit.
  • Для стабільної роботи рекомендовано Windows PowerShell 5.1 або PowerShell 7+.
  • Права адміністратора лише для пунктів із позначкою [ADMIN].

Як працюють оновлення

Під час кожного запуску меню і модулі завантажуються з актуальної робочої версії. Локальну копію звичайного runtime-скрипта Toolkit не зберігає. Встановлюване програмне забезпечення, наприклад BgInfo, є окремим винятком і завжди вимагає явної дії адміністратора.

Як завершити роботу

Оберіть пункт 0. Toolkit очищає власні команди запуску з історії PowerShell і закриває сеанс.
