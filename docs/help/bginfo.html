Встановлення ПЗ

Microsoft Sysinternals BgInfo

Постійна системна табличка для спілкування користувача з техпідтримкою.

Для чого потрібен BgInfo

BgInfo створює інформаційний блок на робочому столі користувача. У Toolkit він використовується не для повідомлень, а як підказка під час звернення до техпідтримки.

SYSTEM INFO

Користувач : DOMAIN\ivanov
Сеанс з    : 16.07.2026 03:12
Підтримка  : +380 67 001 10 12
             дзвінки / Viber / Telegram / WhatsApp

Встановити або оновити

Toolkit завантажує офіційний архів Microsoft Sysinternals або використовує локальний ZIP, перевіряє цифровий підпис і встановлює потрібну розрядність у C:\ProgramData\RaccoonAdminToolkit\BgInfo.

Налаштувати шаблон

Редактор відкривається інтерактивно. Створіть два Custom Fields типу Environment variable:

RACCOON_BGINFO_USER
RACCOON_BGINFO_SESSION_SINCE

Збережіть шаблон як:

C:\ProgramData\RaccoonAdminToolkit\BgInfo\Config\Raccoon-Standard.bgi

Запуск для всіх користувачів

Локальна установка створює загальний ярлик Startup. Допоміжний скрипт запускається в контексті кожного користувача, задає значення поточного сеансу й застосовує шаблон.

Пакет для доменної політики

Спочатку створіть і перевірте еталонний локальний шаблон. Потім Toolkit формує пакет для Computer Startup GPO з підписаними EXE, конфігурацією, helper-скриптом і сценарієм розгортання.

Перевірка стану

Перевіряється наявність потрібного EXE, цифровий підпис, шаблон, helper і загальний автозапуск.

Видалення

Видаляє загальний автозапуск і каталог Toolkit BgInfo. Поточне зображення робочого столу може залишитися до вибору іншого фону або застосування політики.
