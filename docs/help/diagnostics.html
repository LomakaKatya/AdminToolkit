Діагностика

Окремі перевірки для мережі, пристроїв, продуктивності та журналів.

Перевірка TCP-підключення

SAFEMEMORY ONLY

Перевіряє, чи встановлюється TCP-з'єднання з указаною адресою та портом. Корисно для RDP, SQL, пошти, веб-служб і будь-якого сервісу з відомим портом.

Комплексна діагностика Wi-Fi

SAFEMEMORY ONLY

Збирає дані про адаптер, підключення, сигнал, профіль, шлюз, DNS і базову мережеву доступність.

Комплексна діагностика інтернету

SAFEMEMORY ONLY

Розділяє проблему на локальну мережу, шлюз, DNS і зовнішню доступність, щоб не зводити все до фрази «інтернету немає».

Діагностика доступу до сайту

SAFEMEMORY ONLY

Перевіряє DNS, hosts, TCP 80/443, HTTP(S) і TLS. Допомагає зрозуміти, чи проблема в імені, мережі, сертифікаті або самому сайті.

Діагностика віддаленого доступу

SAFEMEMORY ONLY

Перевіряє мережеву доступність і типові компоненти RDP та інших віддалених підключень.

Діагностика друку

SAFEMEMORY ONLY

Показує принтери, драйвери, порти, черги, стан служби Spooler і типові ознаки проблеми друку.

Діагностика зависань і продуктивності

SAFEMEMORY ONLY

Збирає навантаження, пам'ять, диски, події та інші сигнали, які допомагають відрізнити нестачу ресурсів від збою програми.

Локальні користувачі та останній вхід

SAFEMEMORY ONLY

Показує локальні облікові записи й доступні дані про останню активність.

Невдалі входи, подія 4625

SAFEMEMORY ONLYADMIN

Читає журнал безпеки та формує зрозумілий список невдалих спроб входу. Потребує доступу до Security log.

Інструмент не знайдено.
