Розділ 3

Виправлення

Модулі, які не лише діагностують, а й змінюють стан Windows або профілів.

Розділ виправлень змінює систему або дані. Перед запуском прочитайте план дій, який показує модуль.

Очищення кешу 1С

CHANGES USER DATA

Видаляє локальний кеш 1С для виправлення пошкоджених форм, зависань або дивної поведінки клієнта. Незбережені дані у відкритій 1С треба закрити до запуску.

Перезапуск RDP Clipboard

CHANGES SYSTEM

Перезапускає компонент буфера обміну в поточному RDP-сеансі. Використовуйте, коли перестало працювати копіювання між локальним ПК і сервером.

Очищення черги друку

ADMINCHANGES SYSTEM

Зупиняє Spooler, видаляє застряглі завдання й запускає службу знову. Активні черги друку будуть очищені.

Виправлення часу Windows

ADMINCHANGES SYSTEM

Перевіряє роль машини, налаштовує джерело часу, перезапускає W32Time та запитує повторну синхронізацію.

Сумісність RPC мережевого друку

ADMINSECURITY SENSITIVECHANGES SYSTEM

Змінює параметр RPC Privacy для старих принт-серверів або клієнтів. Це security-sensitive обхід сумісності, а не стандартний перший крок.

Очищення кешів профілів

ADMINCHANGES USER DATA

Очищає стандартні кеші в профілях користувачів. Перед виконанням перевірте звіт і переконайтеся, що потрібні програми закриті.
