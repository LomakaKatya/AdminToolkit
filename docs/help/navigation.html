Навігація без зайвого Enter

Головне меню організоване за функціональним призначенням інструментів. Пошук і швидкий доступ залишаються глобальними та доступні з будь-якого розділу.

Функціональні розділи

Головне меню має шість робочих розділів:

  • Інтернет і мережа для TCP, Wi-Fi, DNS, сайтів, віддаленого доступу та RDP-параметрів.
  • Друк для діагностики принтерів, Spooler і RPC.
  • Перевірка обладнання для продуктивності та компонентів RDP-сеансу.
  • Аудит серверів для входів, профілів, часу, повідомлень та інвентаризації.
  • 1С / BAS для кешу та аудиту файлових баз.
  • Встановлення софту для Server Base Kit, облікових записів, ярликів і BGInfo.

F2 відкриває глобальний пошук, а F3 — обране та останні запуски.

Карта розділів

Повна карта показує обидва шари структури: шлях у меню та фізичне розташування скриптів, реєстру й довідки.

Відкрити карту Toolkit

Підтвердження

Усі підтвердження приймаються однією клавішею:

[Y/Д] Так     [N/Н] Ні

Старі словесні підтвердження модулів на кшталт TIME, CLEAN або LEGACY перехоплюються оболонкою й показуються в єдиному форматі.

Пошук

У пошуку текст вводиться звичайно, тому Enter там залишається. Пошук розуміє назви, компоненти та побутові описи проблем, наприклад:

Останні інструменти

Історія останніх запусків зберігається локально для поточного адміністратора в його профілі. Runtime-скрипти при цьому як і раніше виконуються в пам'яті.
