Способи знайти один інструмент

Інструмент зберігається в реєстрі один раз, але може з'являтися в кількох робочих представленнях:

  • Швидкий доступ для виїзду та термінових задач.
  • Знайти причину для діагностики проблеми.
  • Виправити для відновлення функції.
  • Налаштувати та розгорнути для ПЗ, параметрів і GPO.
  • Користувачі та сеанси для RDP, входів і повідомлень.
  • Контроль та звіти для стану й журналів.
  • Каталог для повного списку за компонентами.

Карта розділів

Повна карта показує обидва шари структури: шлях у меню та фізичне розташування скриптів, реєстру й довідки.

Відкрити карту Toolkit

Підтвердження

Усі підтвердження приймаються однією клавішею:

[Y/Д] Так     [N/Н] Ні

Старі словесні підтвердження модулів на кшталт TIME, CLEAN або LEGACY перехоплюються оболонкою й показуються в єдиному форматі.

Пошук

У пошуку текст вводиться звичайно, тому Enter там залишається. Пошук розуміє назви, компоненти та побутові описи проблем, наприклад:

Останні інструменти

Історія останніх запусків зберігається локально для поточного адміністратора в його профілі. Runtime-скрипти при цьому як і раніше виконуються в пам'яті.
