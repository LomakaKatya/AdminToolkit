Аудит файлових баз 1С/BAS

Інструмент читає ibases.v8i у локальних профілях, групує однакові фізичні бази, перевіряє 1Cv8.1CD, розмір і дату останньої зміни. За замовчуванням додатково шукає файлові бази на локальних fixed-дисках.

HTML-звіти з запуску Toolkit зберігаються тут:

C:\ProgramData\RaccoonAdminToolkit\Reports\1CFileBases

Фізичні каталоги старих скриптів у цьому рефакторингу не переміщуються. Змінюється саме логіка меню, тому ризику зламати старі шляхи немає.

Додавання нового інструмента

  1. Додати runtime-скрипт у Scripts.
  2. Додати одну картку до Config/ToolkitMenu.json.
  3. Додати його ID до потрібного функціонального розділу. Один ID можна використовувати в кількох розділах.
  4. Оновити цю карту та відповідну сторінку довідки.
  5. Прогнати Tools/Test-Repository.ps1.
