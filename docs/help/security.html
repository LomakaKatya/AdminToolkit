Позначки та безпека

Що саме обіцяють мітки біля пунктів меню.

Позначки меню

ПозначкаЗначення
[SAFE]Лише читання, перевірка або формування звіту.
[ADMIN]Потрібні права локального адміністратора.
[MEMORY ONLY]Runtime-скрипт виконується в пам'яті та не зберігається Toolkit на диск.
[CHANGES SYSTEM]Змінює службу, параметр Windows, реєстр або іншу системну конфігурацію.
[CHANGES USER DATA]Може видалити кеші або інші дані профілю користувача.
[DOWNLOADS SOFTWARE]Завантажує та встановлює стороннє програмне забезпечення.
[SECURITY SENSITIVE]Може вплинути на захисні параметри системи.

Підтвердження

Для звичайної публікації повідомлення або відкриття редактора достатньо однієї літери: Y або Д. Ризиковані операції можуть мати додаткове попередження всередині модуля.

Дані та конфіденційність

Toolkit не повинен містити паролі, токени, приватні ключі або секрети в публічному репозиторії. Введені адреси, логіни й тексти не відправляються в окрему аналітичну систему Toolkit.

Перевірка коду

Увесь вихідний код доступний у публічному репозиторії GitHub. Перед запуском критичного модуля адміністратор може відкрити відповідний файл у Scripts і переглянути його.
