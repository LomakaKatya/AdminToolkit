Raccoon Admin Toolkit

Вітаю. Але це лише для Windows.

Це не звичайний сайт, а службовий набір діагностичних PowerShell-інструментів для технічних фахівців.

Не запускайте його у браузері, на телефоні або на macOS. Потрібен комп’ютер із Windows та Windows PowerShell 3.0 або новішої версії.

Як запустити

  1. Відкрийте Windows PowerShell від імені адміністратора.
  2. Скопіюйте наведену нижче команду повністю.
  3. Вставте її у PowerShell і натисніть Enter.
